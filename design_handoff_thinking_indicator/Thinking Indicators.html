Thinking indicator — 3 directions
All three run the same simulated request on a loop: thinking → Scout → Analyst → Matchmaker → drafting → answer. Watch a full cycle (~15s) in each frame. When finished, every option collapses to a quiet one-line receipt instead of leaving chrome behind.
A — Whisper line
Most minimal. One shimmering status line; subagents are small named dots that join beneath it and tick off. No card, no borders — the chat stays calm.
B — Work log card
Most transparent. A collapsible card appends one row per step with a live spinner and elapsed time — good when users need to trust long multi-agent runs.
C — Orbit badge
Most on-brand. Subagents are moons docking on an orbit ring around the Perigee mark; active agents expand into a chip naming their task.
